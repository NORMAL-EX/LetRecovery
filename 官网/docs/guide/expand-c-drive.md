# 无损扩大 C 盘

C 盘满了又不想重装？[工具箱](/guide/toolbox)里的 **无损扩大 C 盘** 可以在**保留数据**的前提下，把当前系统的 C 盘扩大。

::: warning 仅桌面可用
该功能只在正常 Windows 桌面里规划；真正的磁盘操作会在**重启进 WinPE**后执行（运行中的系统盘无法在线扩容）。
:::

## 当前开放的扩容方式

当前生产路径只开放纯扩展：

| 方式 | 说明 | 风险 |
| --- | --- | --- |
| **方式一：纯扩展** | 目标 = 当前大小 + C 盘**紧邻其后的未分配空间**。不移动任何数据。 | 低（推荐） |

目标必须是受认证的单 extent C: 卷，并且它的后方在同一磁盘上已经存在连续未分配空间。超出这段空间的目标大小会在写盘前失败关闭。

::: warning 分区搬移尚未开放
压缩或移动后方分区、从左侧供体借空间以及任何 raw block move 当前都没有生产入口。相关 canonical 身份、同一 PhysicalDrive 句柄和可恢复 consume journal 未贯穿全部阶段前，LetRecovery 不会回退到裸盘符授权或试验性搬移。
:::

::: tip 目标大小的下限
目标大小不能小于当前大小，且至少要等于**已用空间 + 1 GB**。
:::

## 流程

1. 在桌面打开**工具箱 → 无损扩大 C 盘**，填入目标大小。
2. 程序规划好方案；本机若**没有可用 WinPE**，会先**自动下载** PE。
3. 安装临时 PE 引导项，**重启进入 WinPE**完成实际扩容。
4. 扩容完成后重启回系统，C 盘已变大，数据保留。

::: tip C 盘后面没有空闲空间？
如果 C 盘紧邻其后没有未分配空间，当前无损扩容任务会停止。请先用其它已验证方式备份并重新规划分区，使目标后方形成连续未分配空间，再重新发起纯扩展；不要把当前版本当作分区搬移工具。
:::

::: danger 重要数据请先备份
虽然当前路径不搬移文件数据，但扩展卷仍会修改分区表和卷边界。扩容前请备份重要数据，并确保过程中不断电。
:::
