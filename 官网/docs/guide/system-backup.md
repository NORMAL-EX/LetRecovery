# 系统备份

**系统备份**页用于把一个分区捕获成镜像文件。

## 格式

| 格式 | 适用 | 压缩 |
| --- | --- | --- |
| **WIM** | 标准格式，兼容性好（推荐）。 | LZX |
| **ESD** | 压缩率更高，文件更小。 | LZMS（solid） |
| **SWM** | 当前生产备份路径未开放。 | — |
| **GHO** | 当前生产备份路径未开放。 | — |

目前只有 **WIM / ESD** 具备完整的稳定卷重绑、同卷私有暂存、完成态校验和原子发布链；SWM/GHO 会失败关闭，不会退回旧盘符或非事务写入。

## 步骤

1. 选择要备份的**源分区**。
2. 选择**格式**与**保存位置**。
3. 填写**名称**（必填）与**描述**（可选）。
4. 目标已存在时，选择是**追加索引**还是取消勾选后**完整替换**（见下）。
5. 点击**开始备份**。

::: tip 名称是必填项
源分区、保存位置、名称三者都填好后，"开始备份"按钮才会可用；描述则可留空。
:::

## 新建、替换与追加

WIM/ESD 有三种明确的输出策略：

- 目标不存在时为**新建**，如果目标在捕获前被其它程序抢占，任务会停止。
- 通过**浏览…**选中既有 WIM/ESD 时，“增量备份（追加到现有镜像）”会自动勾选；保持勾选会在私有副本中**追加新索引（INDEX）**。
- 对既有目标取消勾选后为**完整替换**，会构造并验证一份完整新镜像，不会原地截断旧文件。

::: tip 既有镜像不会被原地修改
替换与追加都先从拒绝写入/删除共享的旧文件句柄建立同卷私有暂存，完整验证后才通过 durable journal 与 handle-CAS 发布。失败会保留旧目标；崩溃恢复也按实时文件身份和哈希收束，而不是只相信路径名。
:::

## 备份正在运行的系统

**当前系统分区**在使用中无法可靠地原地备份，所以图形界面会**经 WinPE**完成：正常端创建受认证的私有 PE 会话，重启后由 PE 原生进度界面消费同一个 WIM/ESD 新建、替换或追加意图。备份非系统分区时可直接进行。

正常系统端的公共 CLI 也支持 WIM/ESD 新建、替换和追加，但只限无需 PE 的 `auto|direct` 任务并固定 `auto_reboot=false`；需要 PE 的系统卷、显式 `via_pe` 和自动重启会在规划阶段失败关闭。PE 端不提供公共 CLI。

在“关于”页打开“显示自动化配置导出（高级）”后，备份页左下方的“生成自动化”会按当前源分区、目标文件、名称、格式及追加/替换选择生成 `cli\backup.json` 和 `cli\run-backup.cmd`，但不会开始备份。当前公共 CLI 只支持 WIM/ESD，因此界面选择 SWM/GHO 时会明确拒绝生成，不会悄悄改成其它格式。

::: tip 自动校验
两种执行模式都会在捕获完成后校验完整镜像，再进行原子发布；校验或发布失败不会把半成品伪装成成功。
:::
