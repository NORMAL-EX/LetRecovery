# 在线下载

**在线下载**页让你不离开 LetRecovery 就能获取资源，分为三个分类标签：

| 标签 | 内容 |
| --- | --- |
| **系统镜像** | 精选、可直接安装的 Windows 镜像。 |
| **软件下载** | 装机后常用的工具。 |
| **显卡驱动** | 常见显卡（GPU）驱动包。 |

## Aria2 加速

下载使用内置的 **Aria2** 引擎并开启**断点续传**。默认并行分片数为 **16**，可在 8 / 16 / 32 三档中选择；单个服务器的连接数仍最多为 16。中断后重试会从已下载处继续。

## 目录来源与校验

LetRecovery 只读取固定 HTTPS 入口 `https://letrecovery.cloud-pe.cn/v3/index.json`，不再回退旧的 v1/v2 目录。该目录可配置为仅使用 API 镜像、仅使用微软官方目录，或合并两者；微软目录通过 Update Metadata Service（Windows 11）和受控 fwlink（Windows 10）获取长期 ESD，并严格校验官方主机、元数据、文件大小和可用哈希。

目录给出的 MD5 或 SHA-256 会一路传递到下载和缓存校验；声明了校验值却计算失败或不匹配时，下载会失败关闭。服务端没有声明哈希时，界面也不会显示“已验证”。

## 从目录进入安装

点击系统镜像的**安装**不会先盲目下载整个文件。程序先把原始 URL 交给**系统安装**页，通过有界 HTTP Range 请求读取远程 WIM/ESD 元数据；ISO 则只读取 ISO 9660/Joliet 目录和其中 `sources/install.wim` 或 `install.esd` 的必要范围。服务器不支持精确 Range、资源在请求间变化或重定向不安全时会停止。

选择具体版本并确认安装后才开始支持续传的完整下载。下载结束后，程序会重新读取本地镜像，并核对所选索引、版本、Build、架构和安装类型，一致后才进入安装流程。

::: tip 简易模式
启用简易模式后，在线下载和工具箱入口会隐藏；简易模式自己的系统卡片仍会按受控目录完成选择与下载。
:::
