# ViaPE 镜像暂存盘选择策略

正常系统端进入 ViaPE 前，需要把安装镜像和离线资源放到重启后仍可访问的普通数据卷。本策略只负责选择暂存位置；受认证配置位于本次私有 boot.wim，目标系统分区、ESP 和启动项仍由各自的边界处理。

## 空间预算

暂存需求固定为“实际会写入该数据卷的全部文件逻辑大小 + 2 GiB”，其中全部文件包括：

- WIM/ESD 或全部 SWM、GHO/GHS 分卷；XP/2003 则累计实际复制的 AMD64/I386 树；
- 通过 `%Windows%\INF\oemN.inf` 和 `SetupGetInfDriverStoreLocationW` 从现有 Driver Store 元数据直接统计的在线第三方驱动包；统计时不复制驱动；
- 实际启用的 PCA 包、版本化用户驱动目录和 UefiSeven 两个文件；
- 最后只加一次固定 2 GiB，用于文件系统簇取整、受限日志、控制文件和事务元数据。

不再按镜像比例、磁盘总容量比例、固定 8–12 GiB 或额外卷保留重复加空间。候选卷的可用空间达到上述唯一公式即可；自动创建的临时分区也严格使用同一字节数向上取整到 MiB。

## 选择顺序

候选卷必须是当前启动会话中可枚举、可写的固定卷或可移动卷，并且 BitLocker 状态明确为未加密。CD/DVD 和虚拟光驱、网络盘、RAM 盘、只读卷以及无法确认可写的卷在候选入口直接排除。选择时综合介质类型、连接方式、是否与安装目标位于同一物理磁盘以及满足唯一容量公式后的剩余空间：

1. 内置 SSD；
2. 介质类型未知的内置磁盘；
3. 内置 HDD；
4. 无法可靠识别连接方式的磁盘；
5. 外置固态磁盘（包括 Windows 报为固定盘或可移动盘的 USB SSD/U 盘）；
6. 其他可写外置存储。

只要任一内置或连接方式可确认的固定存储卷满足容量公式，就不会因为 U 盘剩余空间更大而改选 U 盘。若当前只有目标固定卷可用而最佳现有候选是外置盘，程序会先只读查询目标卷能否缩出满足同一公式的临时分区；可以缩出时仍优先使用固定存储，不能缩出时才回退外置盘。外置候选中，固态盘优先于机械或介质未知的外置盘。

相同等级优先选择与目标不同的物理磁盘，再选择保留空间更多的卷。磁盘号只在当前启动会话中使用；重启到 PE 后继续依赖卷标记和重新枚举结果，不能假定 `PhysicalDrive0`、`PhysicalDrive1` 或盘符保持不变。

## 只有一个 SSD 系统分区时

自动缩卷不是默认首选：

- 已有安全的内部数据卷且镜像较小时，直接使用该卷，避免无必要地修改分区表；
- 镜像不小于 8 GiB、目标卷是内置 SSD、SSD 有足够安全余量且现有候选只是 HDD 或外置盘时，可选择从目标 SSD 缩出临时分区；
- 没有任何现有卷满足空间要求时，可把安全的目标 SSD/HDD 作为最后的缩卷候选。

自动缩卷只允许 NTFS、BitLocker 明确未加密、非外置且能够取得稳定磁盘号和分区号的目标卷。程序先执行 `shrink querymax`，写操作前再次核对盘符仍对应同一物理磁盘和分区，再使用等大的 `desired` 与 `minimum`；任一条件变化或 DiskPart 未完整满足请求都必须停止。

## 兼容与验证

- NVMe/SCM 在 seek-penalty 查询不可用时仍可识别为 SSD；USB、SD、MMC 和 IEEE 1394 视为外置。
- VMware、Hyper-V、VHD 等虚拟磁盘无法可靠判定 SSD/HDD 时按未知类型比较安全余量，不依赖虚拟磁盘枚举顺序。
- BitLocker 已加密、锁定或状态未知的卷不作为 ViaPE 暂存盘；程序不能假定重启后的 PE 已持有解锁密钥。
- 选择逻辑位于 `lr-core/src/data_staging.rs`，必须使用纯数据单元测试覆盖；自动测试和普通开发机严禁真实执行缩卷、格式化、分区创建或删除。
